# Power BI Dashboard Guide – Company Insights 360

## 1. Overview

The Company 360 Power BI Dashboard is an interactive business intelligence solution developed to analyse business performance and present meaningful insights through data visualisation.

The dashboard transforms structured business datasets into interactive reports, allowing users to explore key performance indicators (KPIs), identify trends, compare business performance and understand different aspects of the company's operations.

## 2. Tools & Technologies

- **Microsoft Power BI Desktop** – Dashboard development and data visualisation.
- **Power Query** – Data cleaning and transformation.
- **DAX (Data Analysis Expressions)** – Measures and KPI calculations.
- **Data Modelling** – Establishing relationships between datasets.
- **CSV Files** – Source datasets used for analysis.

## 3. Dashboard Structure

The dashboard is organised into three main analytical pages.

### Page 1 – Executive Overview

**Purpose:** Provides a high-level overview of overall business performance.

This page focuses on presenting important KPIs and business performance indicators in a consolidated view.

Key components:
- KPI cards for important business metrics.
- Overall business performance visualisations.
- Comparative charts and trends.
- Interactive slicers for filtering data.

### Page 2 – Sales & Product Analysis

**Purpose:** Provides a detailed view of sales performance and business trends.

Key components:
- Sales performance visualisations.
- Category-wise and segment-wise comparisons.
- Trend analysis.
- Interactive charts and filters to explore performance.

### Page 3 – Customer & Regional Insights

**Purpose:** Provides further analytical insights into the available business data.

Key components:
- Detailed business performance charts.
- Comparative visualisations.
- KPI-based analysis.
- Interactive filtering and exploration.

## 4. Data Preparation & Transformation

The source data was prepared before dashboard development.

The preparation process involved:
- Importing CSV datasets into Power BI.
- Inspecting data types and column structures.
- Cleaning and transforming data using Power Query.
- Preparing datasets for analysis.
- Establishing relationships between relevant tables.
- Creating calculated measures where required.

## 5. Dashboard Interactivity

The dashboard includes interactive features to make data exploration easier.

- **Slicers:** Filter dashboard information based on selected dimensions.
- **Cross-filtering:** Explore related visualisations through chart selections.
- **KPI Cards:** Display important business performance indicators.
- **Interactive Charts:** Allow users to compare different business metrics.
- **Page Navigation:** Move between analytical pages.

## 6. How to Access the Dashboard

1. Open the `powerbi` folder in this repository.
2. Download the `Company 360.pbix` Power BI dashboard file.
3. Install Microsoft Power BI Desktop.
4. Open the downloaded `Comapany 360.pbix` file.
5. If prompted, update the source file paths to the downloaded dataset location.
6. Refresh the data if required.
7. Explore the dashboard using the available slicers and visualisations.
